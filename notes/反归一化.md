这个函数的作用是将**归一化后的图像张量还原回原始的 [0, 1] 像素值范围**，通常用于可视化（如 `matplotlib` 或 `torchvision.utils.make_grid` 显示图片时）。

下面逐行拆解：

1. 背景：为什么要反归一化？

训练时我们通常对图像做了标准化变换：
$$x_{\text{norm}} = \frac{x_{\text{orig}} - \text{mean}}{\text{std}}$$

这会让像素值变成均值为 0、标准差为 1 的分布（可能有负数），模型训练更稳定。但人眼和显示库只能看 **[0, 1]** 范围的图像，所以需要逆变换还原回来。

2. 数学原理

将上面的公式反过来：
$$x_{\text{orig}} = x_{\text{norm}} \times \text{std} + \text{mean}$$

代码中的 `t.mul_(s).add_(m)` 就是在做这件事。

```python
def denormalize(img_tensor, mean, std):
    img = img_tensor.clone()
    for t, m, s in zip(img, mean, std):
        t.mul_(s).add_(m)
    return img.clamp(0, 1)
```
